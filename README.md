### 🥩 Carnivore Month

I developed Carnivore Month as a responsive meal-planning application designed to make a carnivore lifestyle simpler and more practical.

The system combines personalised planning logic with practical day-to-day tools rather than simply displaying static meal suggestions.

Key functionality includes:

- Deterministic 30-day meal planning
- Personalised meal-plan generation
- Shopping list generation
- Pantry management
- Meal swapping, adding and removing
- Food exclusions and preference controls
- Metric and Imperial measurement systems
- Responsive desktop and mobile layouts
- Progressive Web App capability
- Android integration through Capacitor
- Commercial entitlement architecture
- Analytics integration
- Privacy, legal and data-management functionality
- Structured testing and QA

**Technology:** React, TypeScript, Vite, Tailwind CSS, Capacitor, Android, Google Analytics, PWA architecture and AI-assisted development workflows.

This project has given me practical experience taking an idea from requirements and operational logic through interface design, development, testing, refinement and deployment preparation.

### The Collective Market Portal
